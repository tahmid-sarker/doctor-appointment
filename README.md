# Appointly Health (Doctor Appointment)

- [**View Live**](https://tahmid-sarker.github.io/doctor-appointment/)

Appointly Health is a comprehensive doctor appointment healthcare management system built with React and Vite. It streamlines the process of booking, managing, and tracking medical appointments for patients and healthcare providers.

## Features

- Browse a list of verified, experienced doctors across various specialties.
- View detailed doctor profiles, including education, specialty, chamber, fees, and availability.
- Book appointments and manage your bookings.
- Visualize your appointments with charts.
- Read the latest health blogs and tips.
- Responsive and modern UI with Tailwind CSS and DaisyUI.
- Persistent storage of bookings using local storage.

## Run Locally

To view this project locally, follow these steps:

- **Clone the repository:**

    ```bash
    git clone https://github.com/tahmid-sarker/doctor-appointment.git
    ```

- **Navigate to the project directory:**

    ```bash
    cd doctor-appointment
    ```

- **Install dependencies:**

    ```bash
    npm install
    ```

- **Start the development server:**

    ```bash
    npm run dev
    ```
